# Pulkit Sharma — Portfolio Website

Source code for a personal portfolio built with HTML, CSS and JavaScript.
It presents an introduction, technical skills and project links.

## Preview locally

```bash
git clone https://github.com/BrahminPulkit/Portfolio-Pulkit.git
cd Portfolio-Pulkit
python -m http.server 8080
```

Open `http://localhost:8080`. The entry point is `index.html`; static images,
styles and scripts are under `assets/`. No Node.js build step is required.
